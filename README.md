# Personal Blog with Flask

This project is a personal blog web application built using Flask.

Features:
- User Registration and Login
- Create, Edit and Delete Blog Posts
- Comment System
- SQLite Database
- Responsive Design with Bootstrap

Technologies Used:
Python, Flask, SQLite, HTML, CSS, Bootstrap

Run the project:
python app.py

Open browser:
http://127.0.0.1:5000
